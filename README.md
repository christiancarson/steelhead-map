# Steelhead: the Skeena and Nass

Where you can legally and respectfully fly fish steelhead in the Skeena and Nass,
honouring the Gitxsan and Gitanyow declaration while following BC regulations.

Blue is open. Red is closed by the BC freshwater fishing synopsis. Orange dashed is
closed by the Gitxsan/Gitanyow declaration only, which the province does not enforce.
Click any reach and the popup names which applies.

Boundaries are accurate to about 5 km. Gitxsan Huwilp Government: 250-842-6780.
Check the current synopsis and any in-season regulation changes before you fish.

Built from the BC Data Catalogue, HYDAT, the ECCC Water Office and the Tyee test
fishery. This repository holds the built page only.
